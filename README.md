# Portfolio

This is a small, focused public portfolio of selected personal projects. It introduces each project's purpose, main techniques, organization, and project-specific lessons without mirroring source code or reproducing generic technical references. It is not a complete employment portfolio or a record of every school or personal project; other work can be presented through the CV.

## Project profiles

- [Personal Development Hub](projects/personal-development-hub.md) — a high-level overview of reusable guidance and development resources.
- [At-Home Platform](projects/at-home-platform.md) — a high-level profile of the at-home platform project.
- [ComboCoach](projects/combocoach.md) — a boxing training application.
- [Cloud-native Car Rental Platform](projects/cloud-native-car-rental-platform.md) — a cloud-native car rental platform.
- [CiviC Compiler](projects/civic-compiler.md) — a compiler for the CiviC language.
- [Java Code Quality and Clone Detection Tool](projects/java-code-quality-and-clone-detection-tool.md) — a Java maintainability analysis and visualization tool.
- [Blockchain Freelancer Platform](projects/blockchain-freelancer-platform.md) — a decentralized freelance marketplace developed for the Ethereum testnet.
- [Engagement Visualization Platform](projects/engagement-visualization-platform.md) — a platform for visualizing Degrees of Engagement across projects.

Profiles describe projects or related sets of projects, not one repository apiece; one profile may cover multiple related projects housed in a larger repository. They are self-contained unless an authorized public source is available. Private project profiles do not link to internal evidence or imply private repositories are publicly accessible. CV-supplied statements are attributed as such, and plans or illustrative organization are not presented as verified implementation.
